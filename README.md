# Hun Kimlong — Personal Professional Website

A responsive static portfolio/public professional profile for Hun Kimlong.

## Run

No build tool is required. Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## What to edit

### 1. Profile photo
Replace the placeholder block in `index.html` under `.profile-image` with:

```html
<img src="assets/profile.jpg" alt="Hun Kimlong" />
```

Then put your image at `assets/profile.jpg`.

### 2. Project images
Replace each `.project-image` placeholder with an `<img>` element and your own image.

### 3. Links
Search `data-placeholder-link` in `index.html` and replace each `href="#"` with the real URL.

### 4. Social accounts
Update the Facebook, TikTok, GitHub, LinkedIn, Behance and Dribbble links in the **Official Accounts** section.

### 5. CV
Replace `assets/CV-Hun-Kimlong.pdf` with your latest CV using the same filename, or change the link in `index.html`.

### 6. Public information / media
Only add real articles, interviews, events, publications, or other independent references. Do not add fabricated coverage.
